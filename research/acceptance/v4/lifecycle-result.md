The first identity attempt stopped before emitting opcode204. Its [Activate capture was blank](runs/lifecycle-out/identity-initial-failure/register/activate-submit.png), while the [later failure capture](runs/lifecycle-out/identity-initial-failure/register/failure.png) showed the populated activation form. Decoded opcode203 fields matched the previously passing identity fixture, including activation byte0; no activation request reached the backend. The harness now waits for the original focused-button command and a populated Step3 Canvas after returning from the verification editor, then presses the original FIRE key. A diagnostic retry and the final run using this permanent harness correction both passed without changing or rebuilding the server. Initial captures, logs and database remain under `identity-initial-failure*`; diagnostic captures remain under `identity-diagnostic-pass*`. They are excluded from the totals above.

Each suite used a fresh database and isolated listeners `127.0.0.1:58080` and `127.0.0.1:59119`. The older harnesses advertised their embedded `:8080` page origin while the Connector shim redirected all network requests to isolated ports; catalog advertised `:58080`. Compilation and harness output ran in a new temporary tree. The main backend, interactive clients, main database and previous evidence were untouched. All isolated servers and JVM runners exited; both isolated listener ports were confirmed free afterward.

The harnesses execute original packet builders, dispatchers, UI models, HTML parsing, forms and Canvas rendering through selected reflective calls. They do not exhaustively simulate keypad interaction or establish historical pixel identity for reconstructed server pages. Lifecycle shutdown ordering, context cancellation and forced HTTP draining have separate Go regression tests; successful native scenarios do not exhaust every cancellation timing. The earlier six-suite run before the cancellation corrections is retained separately in [its original report](lifecycle-before-cancellation-fix-result.md).
