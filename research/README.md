## Tracked research and local artifacts

Keep Markdown/HTML reference documents, small JSON catalogs, source URLs, hashes, analysis-tool source and acceptance reports in Git. These explain the findings and how to reproduce them.

The following stay on this machine and are Git-ignored:

- Downloaded applet JAR/JAD files and third-party Java tool JARs.
- Recovered backend download resources under `data/applets/resources/v4`: theme, language, avatar and sprite atlas. These are extracted from the verified publisher JAR and are never embedded in tracked Go source.
- Entire `applets/*/artifacts/` directories: downloaded applets, extracted classes/resources, decompiled source, disassembly and image captures. Research catalogs and capture manifests live separately under each version's `docs/data/`.
- Raw downloads under `applets/*/discovery/`; small JSON/Markdown discovery provenance remains eligible for Git.
- Complete acceptance runs under `acceptance/*/runs/`, including packet captures, screenshots, binaries and SQLite files.
- Generated bytecode/text dumps under the version-specific `docs/data/` directories.
- Compressed source snapshots and logs in architecture evidence, plus the full local relocation manifest.
- Fresh build/test/client output and application databases under the root `data/` directory.

Ignored files remain available locally; this policy does not delete them. A checkout contains the research and tooling, but not every input required to execute the original applets. The [local applet setup guide](../tools/applets/SETUP.md) gives verified download URLs, exact save locations and checksums for running the client. Version provenance notes and the [tool manifest](../tools/applets/bin/manifest.json) cover additional research inputs. The validator checks recovered bytes when the local inputs are present.

Java launchers, compatibility tests and emulator shims under `tools/applets/` remain source-controlled so the research can be reproduced. The Go backend does not compile or run Java and uses synthetic fixtures for its ordinary tests.

## Historical paths and integrity

Retained acceptance runs, source archives and as-run manifests move without content edits. Their embedded paths and the old Go module name describe the execution that produced them. The relocation map resolves those historical paths; it does not rewrite provenance to pretend an earlier run used the current tree.

The detailed per-file pre-move hash manifest is local at `relocation-manifest.json.gz`. Current source references and documentation links use the new layout. Original publisher JARs and captured evidence retain their original bytes.
